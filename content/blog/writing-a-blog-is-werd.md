In previous blogs I tried out AI to code and write them, a little toe dip into vibe coding.
This year, whether I like it or not, Claude Code has become a much larger part of my work day.

Its increasing capability is both exciting and scary, and at the moment I'm trying to balance being productive with not offloading all my thinking to the cloud.

So now is the time to keep learning all I can. Here's what I'm working on.

## What I'm learning in tech

### Working towards a certificate

I've barely started on this path, BUT I have a potential opportunity through work to go for a certificate.

I've been immersed in a lot of Microsoft Azure services at work, but I only really get to manage a small part of it. DevOps is not my area.
Rather than diving further into Azure, I'm looking down the AWS path. It has a lot of great guides and information, and it's certainly a gap in my skills.
I also figure the fundamentals are transferable between the two platforms, and to cloud computing in general.

In particular, I'd like to work towards the AWS Certified Solutions Architect – Associate.
The exam recommends a year of hands-on AWS experience before sitting it. I'm hoping that with a bit of discipline and a few sandboxes I can shorten that.

Somewhat excited to sit an exam again :/

### Improving this website

It seems my friend is better at marketing this website than I am. Not surprising, considering I never intended to, this was a bit of personal fun.
Still, a few more people have been visiting, and they're VERY interested in [Overlap](/games/overlap).

So firstly, we need more Overlap puzzles!

Secondly, I'd like to hook up a database and users, so we can have leaderboards and properly hidden answers.
This would be a good chance to learn some AWS, but to avoid accidentally bankrupting myself, I'm going to learn Cloudflare Workers and D1 instead, and ideally spend no money.

### Homelab

Not sure how much this will progress in the next 6 months, but it would be nice to host a few movies!

## What else I'm learning

### Piano

I learned piano throughout school, though practice between lessons was pretty rare.
A new brother-in-law has got us all back into music, and I've picked it up again as a hobby.

I've gotten pretty good at *Passacaglia* and *Comptine d'un autre été : l'après-midi*, both completely new songs to me.

There are a couple of songs I've had since school.
I'd like to get really good at *Moonlight Sonata* (3rd movement). Page 3 is where it falls apart.
There's another one, A Praeludium, printed from some lesson book, where I'm quite good at the first page, but the second needs some work.

Otherwise, it'd be nice to try singing while I play, which I've never been particularly good at.
And I really need to learn my scales and arpeggios.

I've got one, but let's be honest, we should really just focus on the piano.
